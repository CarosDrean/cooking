## Verificación del toast

El código en `client/src/pages/Recipes.tsx` (líneas 115-135):

```tsx
autoImport.mutate(
    { pantryBonus: makeableOnly },
    {
        onSuccess: (res) =>
            toast(
                res.count > 0
                    ? `Se importaron ${res.importedRecipeCount} recetas y ${res.importedDrinkCount} bebidas según tu perfil ✓`
                    : "No se encontraron recetas nuevas compatibles con tu perfil.",
            ),
        onError: () => toast("No se pudo importar del catálogo.", "error"),
    },
)
```

- **`count > 0`**: Toast muestra "✅ Se importaron X recetas y Y bebidas según tu perfil ✓"
- **`count === 0`**: Toast muestra "No se encontraron recetas nuevas compatibles con tu perfil."
- **Error**: Toast muestra "No se pudo importar del catálogo." (error)

**Resultado:** ✅ La lógica del toast es correcta. Con `count: 10` el toast muestra el mensaje de éxito.

## Problemas encontrados

### [P3] Scores de recetas bajos (0.17-0.22)
- **Ubicación:** `server/src/services/importPipeline.ts` + `importScoring.ts`
- **Descripción:** Las recetas importadas tienen scores muy bajos (apenas por encima de -50). "English Breakfast" obtuvo 0.22 y "Breakfast Potatoes" 0.17. Esto significa que el scoring está siendo muy conservador.
- **Pasos para reproducir:** Importar con el perfil "Oscar" (sin-lactosa, restricciones leche/aji/sillao)
- **Comportamiento esperado:** Scores más altos indicarían mejor match con el perfil
- **Recomendación:** Revisar si las penalizaciones en `scoreRecipe()` son adecuadas. Podría faltar un bonus por compatibilidad dietética con `sin-lactosa`.

### [P3] La segunda importación devuelve bebidas duplicadas parcialmente
- **Ubicación:** `importPipeline.ts` línea 231-233
- **Descripción:** En la segunda llamada se importaron 2 bebidas adicionales (Clove Cocktail, Alice Cocktail) que no estaban en la primera tanda. Esto no es un bug, pero sugiere que el límite `topDrinks.slice(0, 8)` en la primera llamada dejó algunas bebidas sin importar.
- **Comportamiento esperado:** Consistente — es aceptable.

## Recomendaciones
- ✅ El fix funciona correctamente. El botón "⬇ Importar según mi perfil" ahora importa recetas y bebidas de múltiples fuentes según el perfil activo.
- ✅ El toast de éxito se muestra correctamente con conteo de recetas + bebidas.
